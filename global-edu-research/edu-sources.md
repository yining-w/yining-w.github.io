# Global Education Research Sources

This file defines the trusted source list used by the `global-edu-research` skill.
Sources are organized into confidence tiers. Tier 1 sources are weighted most heavily in synthesis and citation.
Edit this file to add, remove, or re-tier sources before running a search.

## Notes on Source Confidence
- **Tier 1** sources should anchor any response when directly relevant. Quote and cite explicitly.
- **Tier 2** sources provide rigorous evidence — use to substantiate claims and add nuance.
- **Tier 3** sources are supporting — useful for context, but should not stand alone as primary evidence.
- If a source outside this list appears highly relevant (e.g., a peer-reviewed journal), it may be cited but should be labelled as outside the core grey literature corpus.
